# Setup Questionnaire
# Answer these before starting. The more detail, the better your agent from day one.
# Your answers go into SOUL.md, IDENTITY.md, USER.md, HEARTBEAT.md.

---

## 1. Your Agent's Identity

- **Name:** What should your agent be called?
  _(e.g. "Claw", "Max", "Nova", "Friday" — something you'll actually use)_

- **Emoji:** One symbol that represents it.
  _(e.g. ⚡ 🦾 🧠 🐾)_

- **Role:** How would you describe what it does for you in one sentence?
  _(e.g. "My chief of staff", "My personal ops assistant", "My second brain")_

---

## 2. Personality & Communication

- **Tone:** How should it sound?
  _(e.g. "Direct and sharp, no filler words", "Warm but efficient", "Calm and data-first")_

- **Language:** What language should it default to?
  _(e.g. German, English, or switch based on context?)_

- **Address:** How should it address you?
  _(First name? Nickname? Formal "Sie"? Informal "du"?)_

- **Reply length:** What's your default preference?
  _(Short and punchy / detailed and structured / depends on topic)_

---

## 3. About You

- **Name:** Your name (as it should appear in USER.md)

- **Timezone:** Your timezone
  _(e.g. Europe/Zurich, America/New_York)_

- **Profession / Business:** What do you do?
  _(Brief description — helps the agent understand your context)_

- **Current top priorities:** What are you working on right now?
  _(Projects, goals, open loops — 3–5 bullet points is enough)_

- **Tools you use daily:**
  _(e.g. Notion, GitHub, Gmail, Calendar, Slack — so the agent knows what to integrate)_

---

## 4. Behavior

- **Pet peeves:** What should the agent never do?
  _(e.g. "Never add filler phrases", "Don't ask for permission on small things", "No bullet points for simple answers")_

- **Proactivity level:** How autonomous should it be?
  _(e.g. "Ask before external actions", "Act first, report after", "Always ask")_

- **Morning routine:** Should it send a daily brief? When? What should it include?
  _(e.g. "08:00 — weather, calendar, top 3 tasks, any urgent emails")_

---

## 5. First Channel

- **Primary chat app:** Where will you mainly talk to the agent?
  _(WhatsApp recommended / Telegram / iMessage / other)_

- **Phone number / handle** for that app _(needed for allowlist security)_

## 6. AI Model

- **Provider:** Anthropic (Claude) / OpenAI / local model?
  _(Anthropic Claude recommended for best instruction-following)_

- **API key ready?** Yes / No _(if no: get one at console.anthropic.com before starting)_

  _(e.g. Gmail, Google Calendar, Obsidian, GitHub, Spotify)_

  _(Search at clawhub.ai)_

  _(Work style, values, quirks, context that helps it help you)_
